# Introduction to IDS

## intrusion
- a violation, or attemp to violate the security policy of system

## threats
- malware
- malicious code
- DDoS/DoS
- spamming
- mailbommbing

## IDS
- gather and analyze information from within a computer or network, to identify any violations of security policy
- referred as packet-sniffer
  

## type of intruders
- outsider
  - from outside network
  - may attack external presence (deface webserver , forward spam through email)
  - may come from internet,
- insider
  - intruderas that legitimately use the internal network
  

## intruder method
- physical intrusion
  - intruder have physical access to a machine
- system intrusion
  - assume intruder already has a low-privilege user
- remote intrusion
  - involves intruder who attempts to penetrate a system remotely
  - begins with no special privileges.

## the need of IDS
- not all traffic may go through **firewall**
- not all threats originates from outside
  
## intrusion sign
- unaccountable disk utilzation
- unaccountbable the file modification
- unaccountable CPU utilization
- network saturation
- unknown process using sockets
- anbormal network / system activity
## advantages IDS
- detecting attacks
  - tell if worm is attacking a network or if a computer system has been compromised
- enforcing policies
  - IDs can monitor and internal networks for behaviour that violates the organization's network security or acceptance use policies
- provide an audit trails
  - provide an after-the-attack audit trail for seeing how far an attacker got, where it came from
  
## disadvantages
- generate false + and -
  - false -
    - cannot detect attack, but actually the data packet is an attack
  - false +
    - detect an attack but actually it is not
- cannot deal with encrypted network traffic

## workflow
- IDS listen to all traffic crosses a network segmentation
- looks at the traffic content to determine normal traffic or possible attacks
- is traffic suspicious, IDS alerts a person in charge

## IDS process cycle
- 1. detection
- 2. analyzing
- 3. post-mortem
- 4. prevention

## component
- packet decoder
  - take packet from different types of network interfaces and prepares them to be **preproccees** or to be sent to the **detection engine**
- preprocessors
  - component or plug-in that can be used with snort to arrange or modify data packets 
- detection engine
  - detect if any intrusion activity exist in apackets
  - load the detection engine depends on:
    - number or rules
    - power of machine 
    - speed of internal bus used
    - load of the network
- logging and alerting system
  - logs are kept in simple text, tcpdump
  - all of the lof files are stored in /var/log
- output module
  - control type of output generated by the logging and alerting system

## limitation (cannot do)
- investigate attacks without human intervention
- analyze all traffic on a very high speed network
- compensate for weak authentication and identification mechanisms
